Project case study

Budgeter

A local-first expense and budget tracker built with React Native, Expo Router and TypeScript. Track spending and income, set monthly budgets per category, and see it all in charts - no accounts, no server, everything stays on the device.

Overview

Most budgeting apps want an account and a connection. Budgeter was built the opposite way: a fast, offline-first tracker you can use one-handed. The goal was a clean daily loop:log a transaction, see what's left this month, and know when a category is running hot - with a premium, modern look.

Key features

  • Add, edit and delete expenses and income
  • Dashboard with spent, income, net and budget left
  • Per-category monthly budgets with live progress bars
  • Search and filters by day, note, category and type
  • Donut chart by category plus a 6-month bar chart
  • Light, dark and system themes with an accent picker

Tech stack

Expo SDK 57 / React Native 0.86 with TypeScript in strict mode. File-based navigation via Expo Router, Zustand with persist over AsyncStorage for local state, and react-native-gifted-charts + SVG for visualisation.

Expo Router TypeScript Zustand AsyncStorage

Architecture

Routes live in src/app (a tab group plus an add/edit transaction modal). Reusable UI sits in src/components, and all money logic - monthly totals, budget rows, category breakdowns and the monthly series - is isolated in src/utils/aggregate.ts so screens stay thin.

Design system

A single indigo primary drives the interface, with expense/income semantics kept separate from branding colour and fourteen switchable accents. Category colours double as the chart legend, so the ring, the progress bars and the list all read as one system.

Challenges & learnings

Keeping aggregation pure and testable was the core lesson: month windows, per-category spend and the rolling six-month series all derive from one transactions array. Persisting partial state with Zustand meant the app survives reloads without a backend.

Roadmap

  • Recurring transactions
  • CSV export
  • Multiple wallets / accounts
  • Custom categories

Status & deliverables

Working Expo app (Android, iOS and web) with source and a written README. Screens above are rendered from the real app theme. Source and a running build are available on request.
